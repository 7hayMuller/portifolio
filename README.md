# Thayná Müller · Portfolio

Personal portfolio of a **Frontend Developer & UX/UI Designer**, with projects, skills, a blog and a contact section.

🔗 **[thaynamuller.com](https://thaynamuller.com)**

Built with Next.js, TypeScript and Tailwind CSS, with a focus on performance, SEO, responsiveness and micro-animations.

---

## Features

### Home (single page with section navigation)
- **Hero:** "Frontend & UX/UI Designer" headline with a shortcut to the contact section. On mobile, the photo sits inside a circle with rotating text around it.
- **About:** introduction and background.
- **Projects:** Swiper carousel of cards with video previews and the project type (Front-end, UX/UI or both). Each card opens a **case study modal** with an image gallery, description, technologies and links (GitHub, Medium, Figma, Behance).

  | Project | Type |
  | --- | --- |
  | Remedia | UX/UI + Front-end |
  | Finny – Cashback Goals | UX/UI |
  | Nearby | Front-end |
  | Itaú – Digital ecosystem | UX/UI |
  | This portfolio | Front-end |

- **Skills & Tools:** interactive 3D scene (Spline) with a description of the skills (React, Next.js, TypeScript, Tailwind, SCSS and Figma).
- **Contact:** form (name, email and message) sent through Formspree, with success and error messages. It also has links to LinkedIn, GitHub, Behance and Instagram, and a "Get in touch" text with a decrypting effect.

### Blog
- List of **Medium** articles with cover image, date and excerpt, linking to the original post.
- Posts come from `public/medium-posts.json`, generated by a script that reads the RSS feed and filters the `javascript` tag.

### General
- **Languages:** Portuguese and English, with automatic detection and a toggle in the navbar.
- **Navbar** that highlights the active section and links to the blog.
- **SEO:** sitemap and `robots.txt` generated by `next-sitemap`.
- **Animations:** Framer Motion, GSAP and Three.js / React Three Fiber.
- **Static site** (`output: "export"`), deployed to AWS.

## Getting started

```bash
git clone https://github.com/7hayMuller/portifolio.git
cd portifolio
npm install
npm run dev        # http://localhost:3000
```

| Script | Description |
| --- | --- |
| `npm run dev` | Development server |
| `npm run build` | Builds the static site into `out/` |
| `npm run lint` | ESLint |
| `npm run sitemap` | Generates the sitemap and robots.txt |
| `node scripts/fetchMedium.js` | Updates the blog posts |

---

## Deploy

On every push to `main`, GitHub Actions:

1. installs dependencies and runs the build
2. syncs the `out/` folder to the S3 bucket
3. invalidates the CloudFront cache

Required repository secrets: `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION`, `S3_BUCKET_NAME` and `CLOUDFRONT_DISTRIBUTION_ID`.
